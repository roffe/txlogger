## Installation

1. Download the [installer](https://github.com/roffe/txlogger/releases/latest/download/txlogger_setup.zip) or the [standalone zip](https://github.com/roffe/txlogger/releases/latest/download/txlogger.zip).
2. Run the installer, or unzip the standalone version anywhere you like.
3. Connect your CAN adapter and start logging.

Requires Windows 10 or newer.

### Nightly builds

For the latest features and fixes, use the nightly [installer](https://github.com/roffe/txlogger/releases/download/nightly/txlogger_setup.zip) or [standalone zip](https://github.com/roffe/txlogger/releases/download/nightly/txlogger.zip).

### Additional downloads

- [Microsoft Visual C++ 2015-2022 Runtime](https://aka.ms/vc14/vc_redist.x64.exe) — required if you get missing VCRUNTIME140.dll
- [Mesa3D for Windows](https://downloads.fdossena.com/geth.php?r=mesa64-latest) — unzip into the txlogger folder if your system lacks proper OpenGL support

See the [FAQ](/docs/faq/) for troubleshooting.
